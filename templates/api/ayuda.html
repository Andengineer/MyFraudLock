Información y Ayuda

Aquí encontrarás orientación para usar el sistema FraudLock.

Estados de los incidentes

  • Pendiente → El incidente aún no ha sido revisado.
  • Fraude confirmado → El incidente ha sido validado como fraude.
  • Falso positivo → El incidente fue descartado, la transacción era legítima.

Interpretación del Score de Riesgo

El sistema calcula un score de riesgo (0-100). Mientras mayor el score, mayor la probabilidad de fraude. El umbral actual es {{ config.umbral_score }}%. Las transacciones iguales o superiores a este valor se marcan como incidentes.

Auditoría

Puedes auditar:

  • Individual: ingresando importe, método de pago y dirección de envío.
  • Por lote: subiendo un archivo CSV con las columnas importe, metodo_pago, direccion_envio.

Soporte

Para consultas adicionales, contacta al equipo de soporte.
